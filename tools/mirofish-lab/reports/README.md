# Report artifacts

- `latest.md` / `latest.json` — generated by `pnpm mirofish-lab:report` from the latest run, scenarios, coverage, and execution results.
- `coverage.json` — machine-readable coverage levels and per-scenario evidence. Evidence is a `file:line — test title` pair from a test block that contains an assertion.
- `execution-results.json` — latest `pnpm mirofish-lab:execute` output.
- `execution-results.after-fix.json` — the post-repair run kept as explicit evidence.
- `execution-results.before-fix.json` — transcript of the real pre-repair failure. It was recorded from the command shown inside the file, not produced by the current `execute` command. It is what makes the defect a reproduction rather than a hypothesis.
- `baseline-scenarios.json` — deterministic contract-only comparison set.
- `baseline-llm.json` — optional LLM-only baseline. It is absent when no key is available; the report then says the comparison is blocked.

`reports/artifacts/` and `runs/` are gitignored: they contain raw Vitest JSON and machine-specific run output. The curated files above are safe to commit and contain no credentials or production data.
