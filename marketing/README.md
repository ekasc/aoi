## Quick Start

**For building the landing page:**
1. Start with `09-landing-page-spec.md` - Complete landing page blueprint
2. Reference `01-value-proposition.md` for messaging and copy

1. Read `01-value-proposition.md` - Core messaging and tone

**For an LLM to build the website:**

## Key Information Summary

**Product:** Aoi - Private scrapbook and planning tool for couples  
**Tagline:** "Keep the moments that matter"  
**Price:** $9.99 one-time purchase  
**Key Features:** Timeline, Calendar, Privacy  
**Target:** Gen Z/Millennial couples who value privacy  
**Differentiator:** No feeds, no algorithms, pay once own forever  
**Theme:** Beach vibes (cyan/coral colors)  
**Tribute:** The cyan color (#4ECDC4) is a subtle nod to Cyan  

## Marketing Principles

✅ **Do:**
- Lead with benefits, not features
- Use "you two" language
- Be warm but clear
- Emphasize privacy
- Show authentic moments

❌ **Don't:**
- Mention Cyan by name (keep it subtle)
- Use corporate buzzwords
- Overpromise
- Be too salesy
- Compromise on privacy messaging
