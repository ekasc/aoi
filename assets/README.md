# `assets/` — what ships and why

Bundled files (the complete set — nothing else belongs here):

- `images/icon.png` (1024) — app icon: kept-page + seal on ivory.
- `images/android-icon-foreground.png` (1024, transparent) — adaptive
  foreground, mark in the safe zone.
- `images/android-icon-background.png` (512) — flat ivory.
- `images/android-icon-monochrome.png` (432, transparent) — white mark
  silhouette for themed icons.
- `images/splash-icon.png` (1024) — centered mark on ivory.
- `images/favicon.png` (48) — web icon.

All six are generated by `scripts/gen-app-icons.mjs`
(`node scripts/gen-app-icons.mjs assets/images`) — flat Editorial Paper
shapes only (ivory `#FCF9F2`, moss `#334E45`, clay `#8A3E28`), no
stock, no AI filler, no unknown provenance. Regenerate rather than
hand-edit.

Deliberately absent: illustration files, demo photography, font binaries,
video, texture overlays, template artwork. Empty states, covers, and the
envelope system are code-native (typography, rules, seal-dot geometry,
user photography). See `docs/design/asset-manifest.md`.
